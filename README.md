# Random Password Generator

A simple React-based web application that generates strong and secure random passwords. This project helps users create passwords of varying lengths with a combination of letters, numbers, and special characters.

## Live Demo

Check out the live project here: [Random Password Generator Live](https://vercel.com/darshs-projects-3c8fe174/courses-yrh8)

## Features

- Generate passwords with customizable length
- Include uppercase letters, lowercase letters, numbers, and symbols
- Copy password to clipboard with a single click
- Simple and responsive user interface built with React

## Technologies Used

- **React** - Frontend framework
- **JavaScript** - Logic for password generation
- **HTML & CSS** - Styling and layout
- **VS Code** - Development environment
